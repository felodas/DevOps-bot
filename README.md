# DevOps-bot

## 📖 О проекте

Этот репозиторий представляет собой коллекцию сценариев автоматизации с использованием **Docker** и **Ansible**, созданных для упрощения и автоматизации типовых задач DevOps. Здесь собраны практические инструменты для подготовки, настройки и управления инфраструктурой как кодом.

Основная цель — предоставить готовые, хорошо задокументированные скрипты автоматизации, которые можно адаптировать под различные окружения: от локальной разработки до стейджинга, приближенного к продакшену.

## ✨ Возможности

*   **Контейнеризация с Docker:** Упрощает развертывание приложений, обеспечивает единообразие окружений и позволяет легко масштабировать сервисы.
*   **Управление конфигурациями с Ansible:** Автоматизирует установку ПО, настройку серверов и развертывание приложений на множестве хостов.
*   **Сценарный подход:** Все задачи автоматизации разбиты на понятные сценарии, что упрощает их изучение и повторное использование.

## 🚀 Быстрый старт

Следуйте инструкциям ниже, чтобы скопировать проект к себе на машину и запустить его для разработки или тестирования.

### Необходимые компоненты

Перед началом работы убедитесь, что у вас установлены следующие инструменты:

*   **Docker** и **Docker Compose**: Для запуска контейнеризированных приложений. [Руководство по установке](https://docs.docker.com/get-docker/)
*   **Ansible**: Для автоматизации и управления конфигурациями. [Руководство по установке](https://docs.ansible.com/ansible/latest/installation_guide/intro_installation.html)
*   **Git**: Для клонирования репозитория.

### Установка

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/felodas/DevOps-bot.git
    cd DevOps-bot
    ```

2.  **Настройте переменные (если применимо):**
    В сценарии `docker` в файле bot.py следует поменять значения переменных, такие как токен бота(`BOT_TOKEN`) и т.д. В будущем планируется переделать оба сценария, чтобы можно было сразу написать .env файл.
   

## 🔧 Использование
По дефолту у нас стоит ветка main, так что нам нужно в обязательном порядке переключиться на желаемый сценарий, будь то docker или ansible, с помощью следующей команды:
```bash
git checkout ansible
git checkout docker
```

### Запуск с помощью Docker

Перейдя в ветку `docker`, используйте Docker Compose для сборки и запуска сервисов:

```bash

docker-compose up -d
```

Эта команда соберет необходимые образы и запустит контейнеры в фоновом режиме.

### Запуск плейбуков Ansible

Перейдите в ветку `ansible`, затем в директорию `ansible/` и выполните нужный плейбук:

```bash
cd ansible
ansible-playbook -i tg_bot_playbook.yml
```

Убедитесь, что ваш инвентарный файл (`inventory`) содержит правильные адреса целевых хостов.
